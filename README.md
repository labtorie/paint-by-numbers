# Раскраска по номерам

Веб-приложение, которое превращает фото в раскраску по номерам: контуры, номера цветов и палитра. Всё считается в браузере, фото никуда не отправляется.

**Открыть:** https://labtorie.github.io/paint-by-numbers/

## Как устроен алгоритм

1. Билатеральное сглаживание в Oklab — убирает шум, не трогая края.
2. Карта значимости — где в кадре структура, а где фон.
3. Палитра — взвешенный k-means со сжатием плотности, чтобы редкие, но важные цвета не терялись.
4. Разметка — модель Поттса с учётом краёв вместо «ближайшего цвета».
5. Слияние областей с адаптивным порогом: мелкие области остаются только в значимых и контрастных местах.
6. Векторизация — общие границы трассируются один раз и сглаживаются в кривые Безье.

Экспорт: SVG, PNG, печать / PDF.
